# Collection capture and processing: four review passes

1. **Collection boundaries.** Replaced whole-document link collection with an explicitly selected, supported TikTok grid. Chromium fixtures select 20 posts while unrelated grids, hidden tiles, nested grids and hydration-only posts coexist. Only the selected 20 are returned. Unsupported grids cannot fall back to scanning the document.
2. **Repeat imports and navigation.** Bound progress to the selected grid, separated nested-grid membership, and restricted resume anchors. Selection snapshots the page/title/tab context immediately, so changes before the popup reopens also stop capture. Browser checks cover changed headings, routes, replaced roots and a second selection; popup checks cover resume, lost bookmarks, cancellation, failed batches and Stop.
3. **Processing failures.** Reproduced the reported extra evidence `label` using mocked Claude responses. Invalid tool records receive one fresh schema-validated attempt; repeated invalid output produces a concise error. Connection establishment retries once; read timeouts are not automatically retried. Tests preserve quote verification, source text, usage accounting and error redaction.
4. **Workflow regression.** FastAPI integration verifies that 20 imported links create no processing/download jobs. All 57 Python checks, popup and extension boot checks, and Chromium collection checks passed. A generated video passed real local transcription and frame OCR. Shell and JavaScript syntax and patch whitespace checks passed.

The browser uses synthetic TikTok markup, not a logged-in live account. If TikTok changes its grid attributes, selection must refuse import until that layout is supported. Reselect after reloading the page; progress from legacy whole-page scans is deliberately not reused. A network outage can still require manual retry. No existing Mac imports were deleted by this update.
